# AziziChat

A full-stack real-time chat application built using modern web technologies.  
It allows users to communicate instantly, manage contacts, and store messages securely.

---

## 🚀 Features

- User registration and login
- Real-time messaging using Socket.IO
- Contact list management
- Message storage in database
- Last login tracking
- Secure password hashing

---

## 🛠️ Tech Stack

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Node.js
- Express.js
- Socket.IO

**Database:**
- Azure SQL Database

**Security:**
- bcrypt
- Helmet
- dotenv

**DevOps:**
- Docker
- GitHub Actions
- Azure App Service

---

## ⚙️ How to Run Locally

```bash
git clone https://github.com/azizi12084/AziziChat.git
cd AziziChat
npm install
node server.js
```
